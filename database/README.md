# Pocket Arcade Database

نسخه فعلی برای ذخیره اطلاعات از localStorage مرورگر استفاده می‌کند.

اطلاعات ذخیره‌شده:
- رکوردهای بازی‌ها
- تنظیمات حالت روشن و تاریک

## نکته

این پروژه فعلاً بک‌اند و دیتابیس سروری ندارد.

برای ذخیره حساب کاربران، رکوردهای آنلاین و جدول رتبه‌بندی جهانی، باید یک API و دیتابیس سمت سرور اضافه شود.
